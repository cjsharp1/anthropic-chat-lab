Anthropic Chat Lab

0 / 0 steps

A teaching app for the Anthropic certifications: a simple TypeScript chat client over the Claude API, with a live log panel, example tools, and switchable orchestration patterns. Every file is commented with a plain-language overview of what it does.

How to use this plan. Work top to bottom. Each step is sized for under 30 minutes and ends with a done-check you can run or see. Tick the box when the check passes — your progress is saved in this browser, so open this file from the same path each time. If a step stalls, paste it back to Claude and ask for it to be split into 23a, 23b, and so on.

This plan sits in docs/ inside the project it describes. Every path in the steps below is relative to the project root — the folder above this one — and that is where you run every command.

If a step stalls

Paste the step back and ask for a split. A step is worth splitting when any of these is true:

  • It touches more than two files at once.
  • The done-check needs several separate things to be true.
  • You cannot see a result until the whole step is finished.
  • It has run past 30 minutes and is not nearly done.

Steps 41, 53 and 54 are the likeliest candidates — loops and multi-call patterns have the most places to go wrong.
