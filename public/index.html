Sent as the top-level system field, not as a message. It is resent on every request, so a long one costs input tokens every turn — which is exactly why it is the natural thing to cache.

Caching is a prefix match: the API renders a request as tools → system → messages, and a cache entry covers everything up to a breakpoint. Any byte that changes before it invalidates the lot. The minimum prefix is 1,024 tokens (2,048 on Haiku), and a shorter one is silently not cached — which is why enabling tools usually matters more than the prompt.

Loading…

This does not control whether Claude thinks. On these models thinking is always on and always billed — display only decides whether the thinking blocks come back with text in them. The default is "omitted": reasoning you paid for and cannot read. Turn it on, ask the same question twice, and compare the output tokens — they barely move. budget_tokens is gone; depth is output_config.effort instead. Adaptive thinking also decides whether to reason: an easy question with a terse prompt often returns no thinking block at all, so ask something hard enough to be worth thinking about.

Loading…

output_config.effort — what replaced budget_tokens, which is now a 400 on every model here. A budget was a token ceiling you had to guess; effort is a dial, and the model decides what the level is worth for the question in front of it. Measured on Haiku (npm run try-effort): on a hard question low spent 2,438 output tokens and xhigh 6,501 — 2.7× the cost, for an answer the same length, because the extra went into reasoning. On an easy one ("what does end_turn mean?") max cost 5.2× what low did and returned the same answer: effort you pay for and do not receive. At max the model can also spend the entire max_tokens budget thinking and return no answer at all, with stop_reason: "max_tokens". Note the defaults differ by model (medium on Opus 5.5 and Haiku 5.5, high on Sonnet 5.5), so comparing two models without pinning this compares two effort levels as well.

API key

Checking…

This is the only setting with a Save button. Every other setting on this page saves itself the moment you change it, by writing to your browser's local storage. A key written there would be readable by any script on the page, so this one is sent to the server instead and held in memory — and a send can fail, which is what Save and the message above are for.

Get a key from console.anthropic.com. It is held in the server's memory for as long as the server runs, and is never stored in your browser — so it is gone when you stop the server. To skip retyping it, put ANTHROPIC_API_KEY in a .env file instead; that file is git-ignored.
